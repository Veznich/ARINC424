# Процесс работы

1. Пользователь → **`@si`** (Studio Director)
2. Director определяет директоров; **PM** декомпозирует
3. Специалисты выполняют (код после «сделай/исправь»)
4. **Unit Tester** — юнит-тесты
5. **Integration Tester** — связки систем
6. **Performance Tester** — FPS / память
7. **UI Tester** — 4 разрешения / SafeArea
8. **QA** — функционал / устройство
9. **Automation Tester** — CI (только по запросу)
10. **QA Lead** → **QA Director** принимают
11. **doc-writer** обновляет документацию проекта

**`@СИ`** (кириллица) — техсоветник DeepSeek, не раздаёт студию.

Фаза: по чеклисту приёмки проекта.

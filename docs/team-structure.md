```

├── Project Manager
├── Producer
├── Tech Lead (+ @СИ по запросу)

│   ├── UI Developer
│   ├── AR Engineer

│   └── doc-writer
├── Game Design Lead → designers…
├── Art Director → artists…
├── Sound Director → sound…
├── Tech Director → DevOps, Security, Rollback
├── QA Director
│   ├── QA Lead
│   ├── QA Engineer
│   ├── Unit Tester
│   ├── Integration Tester
│   ├── Performance Tester
│   ├── UI Tester
│   ├── Automation Tester
│   └── Scene Auditor
├── Analytics Director → Analyst
├── Monetization…                  ← по запросу
└── LiveOps…                       ← по запросу
```
